# Data Structures and Algorithms (DSA) Labs

This repository contains my C programming lab solutions for the Data Structures and Algorithms course.

## 📁 Repository Structure

* **`lab1code`**: Implementation of basic 1D array operations.

## 🛠️ Lab 1: Array Operations Covered

1. **Array Traversal**: Printing elements of an array.
2. **Linear Search**: Searching for an element sequentially.
3. **Min / Max**: Finding the minimum and maximum values.
4. **Insertion**: Inserting elements at the beginning, at a specific position, or at the end.
5. **Deletion**: Deleting elements from the beginning, a specific position, or the end.
